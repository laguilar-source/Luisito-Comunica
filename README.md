# 🌍 Luisito Clima

Aplicación web estática de pronóstico del clima con temática inspirada en **Luisito Comunica**, lista para desplegar en **GitHub Pages** sin necesidad de servidores ni claves API.

## Características
- **100% Estática (HTML, CSS y JS puro):** Compatible directamente con GitHub Pages.
- **Sin API Key:** Utiliza la API pública y gratuita de [Open-Meteo](https://open-meteo.com/) sobre HTTPS.
- **Pronóstico actual y a 5 días:** Temperatura, sensación térmica, humedad, velocidad del viento y frases dinámicas según el clima.

## Cómo subir a GitHub Pages
1. Descomprime este archivo `.zip`.
2. Sube `index.html`, `style.css`, `app.js` y `README.md` a la raíz de tu repositorio en GitHub.
3. Ve a **Settings → Pages** en tu repositorio.
4. En **Source**, selecciona `Deploy from a branch`, elige la rama `main` y la carpeta `/ (root)`, y haz clic en **Save**.
